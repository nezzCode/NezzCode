### 📅 Dynamic University Timetable Generator
**Team Software Project**

A dynamic scheduling system that generated course timetables from CSV data while considering room availability, lecturer schedules and timetable clashes.

The system was designed to:
- Import course and scheduling information from CSV files
- Match classes with available rooms
- Detect room, course and lecturer conflicts
- Generate individual course timetables
- Display the final schedule through a polished user interface
 
Partway through the project, our active team changed from four contributors to three. We reassessed the workload, redistributed responsibilities and maintained progress without reducing the quality of the final solution. We completed the core scheduling functionality and delivered an improved frontend that exceeded the original project expectations.
